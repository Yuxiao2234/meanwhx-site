# Design direction

## Concept

**The café-library next door.**

The site should feel like a small human room adjacent to technical research, not like a software dashboard and not like a luxury e-commerce template.

The visual tension is:

- editorial / literary
- precise / mathematical
- warm / ordinary
- slightly strange
- quiet enough for poems and serious objects to share a page

## Palette

```text
paper        #f4f0e7
paper-deep   #e9e1d3
paper-light  #fbf9f4
ink          #23211d
ink-soft     #625e56
sage         #66755e
clay         #a45f45
lilac        #81708f
```

Accent colors should be sparse. The page should mostly read as paper + ink.

## Type

No web-font dependency.

Display:
`Iowan Old Style → Palatino → Georgia`

Interface/body:
`Avenir Next → Segoe UI → system-ui`

Technical metadata:
system monospace.

The mixed typography is intentional: a humanist reading voice with restrained technical annotations.

## Layout

- generous margins
- long horizontal rules
- ledger/editorial rows instead of repeated floating cards
- short navigation
- no dashboard chrome
- almost no rounded containers
- no decorative gradients
- no giant glassmorphism panels
- no fake model visualizations

## Motion

Almost none.

Hover transitions are brief and optional. Reduced-motion preferences are respected.

## Imagery later

Prefer:

- real desk/worktable photography
- material close-ups
- jewelry/object studies
- handwritten or printed notes
- café details
- real gatherings with participant consent
- diagrams with accurate provenance

Avoid making generic AI-generated surreal imagery the dominant brand language.

If generated imagery is ever used, label it internally and make sure it is a deliberate artwork rather than filler.

## Homepage object sketch

The current hero uses CSS-drawn paper, cup, pendant, and books.

It is intentionally modest. Replace it later with one excellent real photograph or commissioned illustration rather than a collage of generic “future AI” imagery.
